# 01 - Filtering

Keep some elements, drop the rest. The result has the same element type and the same order as the source.

| Method | Exercises | One-liner |
|--------|-----------|-----------|
| [Where](Where/README.md) | 10 | Keep elements that satisfy a predicate |
| [OfType](OfType/README.md) | 7 | Keep elements that are a given type (skips nulls) |

Start with `Where` - it is the operator you will use most. `OfType` matters when you meet non-generic
collections or mixed-type lists.
