# 11 - Concatenation

Glue sequences (or single elements) together without removing anything.

| Method | Exercises | One-liner |
|--------|-----------|-----------|
| [Concat](Concat/README.md) | 7 | First sequence, then the second |
| [Append](Append/README.md) | 7 | One extra element at the end |
| [Prepend](Prepend/README.md) | 7 | One extra element at the start |

None of these mutate the source - they return new (deferred) sequences.
